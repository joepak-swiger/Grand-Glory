# Testing and browser evidence

Run `npm install`, then `npm run typecheck`, `npm run test`, `npm run build`, and `npm run test:e2e`. Playwright needs Chromium (`npx playwright install chromium`). CI installs Chromium with its Linux system dependencies before browser tests.

Vitest covers deterministic simulation including movement, boundaries, targeting, cooldowns, hit detection, health and invulnerability, enemy knockback, spawn bounds/distribution/reproducibility, death/XP, leveling and pending choices, upgrades, boss attacks/telegraphs, pause, end states, restart, visual metadata, seeded behavior, and cleanup. Facing regressions cover right defaults, horizontal turns for all enemy kinds, vertical/idle retention, knockback independence, aimed boss orientation, unchanged world collision positions, restart defaults, and independent animation clocks.

The Playwright suite runs the actual Vite application in Chromium at `/?test=1`. That deterministic accelerated path shortens the run for repeatable checks; it does not represent a normal three-minute playthrough or human testing. It checks the real portrait and sprite assets, frame advancement, facing/mirroring, combat, upgrade choice and effect, pause, boss, victory, defeat, restart, console/page errors, and failed asset requests.

Browser evidence is captured in `artifacts/evidence/` by `npm run test:e2e`, including title, standing/moving Blue Pinwheel, left-facing Blue Pinwheel, mixed enemy facing, active combat, upgrade choices, boss, victory, and defeat. Evidence is only valid when generated by the actual browser suite; it is not synthesized from the test setup.

The earlier simulation load check ran 300 fixed steps with 0, 25, and 75 enemies. Its warmed median batch timings were 0.21 ms, 0.63 ms, and 1.82 ms on Node 24.22.1. These machine-specific numbers measure simulation time only, not browser rendering. Animation rendering performance has not been profiled separately. A normal-duration human playthrough has not been recorded.
